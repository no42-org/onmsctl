# Third-Party Licenses

This file is generated by `make licenses` (which runs `cargo about generate`
against `about.toml` and `about.hbs`). Regenerate after adding or updating
crate dependencies and commit the result.

The allowed license set is defined in `deny.toml`. Pull requests that
introduce crates with disallowed licenses will fail CI (`cargo deny check`).
